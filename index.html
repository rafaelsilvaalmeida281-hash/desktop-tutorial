Política de Privacidade

Última atualização: 2 de agosto de 2026.

O aplicativo Bot Discord TikTok foi desenvolvido para verificar os vídeos públicos mais recentes da conta do TikTok autorizada pelo usuário e enviar o link de novos vídeos para um canal do Discord previamente configurado.

Dados acessados

Mediante autorização do usuário, o aplicativo poderá acessar informações básicas da conta do TikTok e dados públicos dos vídeos, como identificação, título, descrição, data de publicação e link público.

Uso dos dados

Os dados são utilizados exclusivamente para identificar quando um novo vídeo público for publicado e enviar seu link ao canal do Discord configurado pelo usuário.

O aplicativo não publica, edita nem exclui vídeos no TikTok.

Compartilhamento de dados

As informações não são vendidas, alugadas ou compartilhadas para fins comerciais. O link público do vídeo poderá ser enviado ao Discord conforme autorizado e configurado pelo próprio usuário.

Armazenamento

O aplicativo poderá armazenar apenas a identificação do último vídeo detectado, com a finalidade de evitar o envio repetido do mesmo conteúdo.

Segurança

São adotadas medidas razoáveis para proteger as informações acessadas pelo aplicativo. Nenhum sistema é completamente seguro, mas o aplicativo limita o acesso apenas aos dados necessários para seu funcionamento.

Revogação de acesso

O usuário poderá revogar a autorização do aplicativo nas configurações de segurança e de aplicativos conectados da conta do TikTok.

Alterações nesta política

Esta Política de Privacidade poderá ser atualizada quando houver mudanças no funcionamento do aplicativo. A data da última atualização será informada no início desta página.
